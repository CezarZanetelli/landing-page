# 🚀 Landing Page — Cezinha in Coming Programation 2027

Projeto desenvolvido como parte da minha jornada de aprendizado e evolução na área de **Programação e Tecnologia**.

A aplicação consiste em uma **Landing Page responsiva**, desenvolvida com HTML5 e CSS3, apresentando conteúdos relacionados a desenvolvimento, tecnologia e minha trajetória como programador.

## 📸 Sobre o projeto

A página possui uma estrutura moderna e responsiva, com navegação por seções e diferentes componentes visuais.

Entre as principais seções estão:

* 🏠 **Home** — apresentação do projeto
* 📚 **Intro** — principais aprendizados
* 🖼️ **Gallery** — galeria de imagens
* 💰 **Pricing** — tabela de informações
* 📩 **Contact** — formulário de contato

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Git
* GitHub

## 💻 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/CezarZanetelli/seu-repositorio.git
```

### 2. Entre na pasta

```bash
cd seu-repositorio
```

### 3. Execute o projeto

Como o projeto utiliza HTML, CSS e JavaScript, basta abrir o arquivo:

```text
index.html
```

Você também pode utilizar uma extensão como **Live Server** no Visual Studio Code para executar o projeto localmente.
